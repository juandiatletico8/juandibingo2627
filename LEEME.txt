JUANDIBINGO WEB v2

Para actualizar la web en GitHub:
1. Abre el repositorio juandibingo2627.
2. Sustituye index.html y la carpeta assets por los de este paquete.
3. Confirma los cambios (Commit changes).
4. GitHub Pages volverá a desplegar automáticamente la misma URL.

La web está optimizada para móvil. Los botones PANEL GENERAL y GOLES DE EQUIPOS cambian de sección sin cambiar de página.
